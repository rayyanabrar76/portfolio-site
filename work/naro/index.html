Naro, an AI video studio

Naro is my own product. You paste a script and Naro turns it into a finished video: AI plans every scene, draws an illustration for each one, reads the script aloud and adds captions that match every word.

01 / The idea

Why I built it.

Making a narrated video by hand means hours of recording, drawing and editing. I wanted a tool that does the whole job from one written script.

Naro ships as a Windows installer that sets up everything it needs. It can use Google Gemini, or a fully local AI model through Ollama, so it can run with nothing leaving your computer.

02 / What I built

The features.
Built end to end.

AI scene planning

The AI splits the script into scenes and decides what each scene should show.

Illustrations

An illustration for every scene, drawn from documentary-style templates.

Narration

Natural-sounding AI voices read the script exactly as written.

Word-synced captions

Captions timed word by word, so they match the voice exactly.

Ready to upload

A finished MP4 with a thumbnail, plus a title, description and tags to copy.

One-click install

A Windows installer that sets up Python, the AI models and everything else.

03 / Built with

The tools,

PythonThe whole video pipeline, from script to finished MP4.
